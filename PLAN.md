# Project roadmap

The implementation follows the versioned roadmap tracked in the GitHub [Map Maker Roadmap project](https://github.com/users/Lumenlum/projects/1).

## v0.1.0 — Project foundation

- [x] Choose the initial stack: Vite, React, TypeScript, Vitest, and Prettier.
- [x] Establish the browser application structure.
- [x] Add development, testing, and formatting setup.
- [x] Create the initial application shell and fixed rainbow theme system.

## v0.2.0 — Map creation and viewer

- [ ] Create maps with optional title, game association, and cover image.
- [ ] Upload and display a base map image.
- [ ] Add pan and zoom controls.
- [ ] Add homepage map cards and map opening flow.

## v0.3.0 — Markers and location details

- [ ] Add, move, edit, and delete markers.
- [ ] Add the initial marker categories.
- [ ] Add marker notes and image attachments.
- [ ] Add Undo and Redo.

## v0.4.0 — Overlays, layers, and filtering

- [ ] Add region/border overlay upload and alignment.
- [ ] Add layer visibility controls.
- [ ] Add marker-category filtering.
- [ ] Add autosave checkpoints and recent-change history.

## v0.5.0 — Accounts and saved maps

- [ ] Add email/password authentication.
- [ ] Evaluate and, if practical, add Google sign-in.
- [ ] Add authenticated map persistence.
- [ ] Add saved-map management.

## v0.6.0 — Sharing and map copying

- [ ] Generate view-only share links.
- [ ] Allow unauthenticated viewing of shared maps.
- [ ] Allow authenticated users to copy shared maps.
- [ ] Ensure copied maps are independent snapshots.

## v1.0.0 — First polished release

- [ ] Complete end-to-end validation.
- [ ] Improve accessibility, responsive layout, and error handling.
- [ ] Add security and privacy review.
- [ ] Finalize documentation and release notes.

# Changelog

All notable changes to Map Maker are documented here.

## Unreleased

### v0.2.0 — Map creation and viewer

- Added a map workspace that accepts image uploads and drag-and-drop.
- Added editable map title and game/world metadata.
- Added zoom controls with percentage display and reset.

### Added

- Established the `v0.1.0` Vite, React, and TypeScript application foundation.
- Added a responsive Map Maker workspace shell.
- Added fixed rainbow accent presets with light and dark variants.
- Added initial build, test, lint, and formatting scripts.
- Added a theme-preset test and project-local documentation.
